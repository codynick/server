# Block Coding

Open `http://10.42.0.1/blocks/` to build a program from visual blocks. The block editor
stores its workspace on the Pi and generates Python for the same installed
`active_script.py` used by the Python IDE.

Review the generated program before running it, especially loops and hardware cleanup.
After generating code, open the Python IDE to run it and see its live terminal output.

Block coding currently focuses on CodyNick core operations. Use the Python IDE for
camera, OCR, speech, and advanced AI examples.
