# Welcome to CodyNick

CodyNick is a Raspberry Pi learning environment for Python, physical gadgets,
IoT dashboards, computer vision, speech, and text recognition. This documentation
is stored on the Pi and remains available without internet access.

## Main pages

| Tool | Address while connected to the Pi hotspot |
| --- | --- |
| Main panel | `http://10.42.0.1/` |
| Python IDE | `http://10.42.0.1/code/` |
| Block coding | `http://10.42.0.1/blocks/` |
| Dashboard | `http://10.42.0.1/dashboard/` |
| Documentation | `http://10.42.0.1/docs/` |

The Pi hotspot address is always `10.42.0.1`. Internet access is normally supplied
through Ethernet or the USB Wi-Fi dongle while the built-in Wi-Fi provides the
CodyNick hotspot.

## Start safely

1. Connect the required CodyNick gadget, webcam, microphone, or speaker.
2. Open the Python IDE.
3. Open a bundled example or write a small program.
4. Select **Run This File**.
5. Watch the live terminal below the editor.
6. Stop the script before unplugging hardware.

Student work belongs in the normal user folders. **CodyNick Examples** is managed by
the installer and is replaced during every repair or upgrade.
